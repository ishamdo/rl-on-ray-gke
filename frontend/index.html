RL Trainer

How it works
  1. Clicking Start Training connects the driver to the Ray head and instantiates a remote RLTrainer Ray Actor on a GPU worker.
  2. Ray's autoscaler detects the num_gpus=1 resource requirement and triggers KubeRay to scale up a Spot GPU node (via ray-gpu).
  3. The Actor loads the Qwen model with LoRA adapters and evaluates GSM8K math questions.
  4. For each question, it samples multiple answers, scores them rule-based (correct/incorrect), calculates relative advantages (GRPO), and optimizes model policy.
  5. Loss and Accuracy (Avg Reward) charts update live. When stopped, the idle GPU node is automatically reclaimed.
